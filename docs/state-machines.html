FOD Vision State Machines

Three machines, one inside the next. The Vision object runs a capture thread; every frame that thread produces moves tracks through a confidence hysteresis; and the robot's loop turns one boolean from those tracks into a commanded speed.

Vision lifecycle▸ frame cycle▸ track state▸ zone_blocked() · age▸ STOP / SLOW / FAST

1The Vision object

Constructing Vision only reads the bundle. Entering the with block opens the camera, starts the daemon thread and waits for the Hailo device; the thread then loops the six-step frame cycle until the block ends. Anything the thread raises parks the object in Failed for good.

2One track

A track has two independent axes, and the flicker on each is damped by a different mechanism. Its state is where the confidence EMA sits between two thresholds, promoted at 0.5 and demoted only below 0.25. Its presence is a miss counter: an unmatched frame freezes the track instead of dropping it, and only the sixth miss ends it.

3The robot's speed

The control loop polls at 20 Hz and reads two things: age and zone_blocked(). Stale vision means stop, never "clear floor". A blocked zone means slow, and the robot keeps re-arming a hold-off so it stays slow until the object has passed under the drum — that timer belongs to the robot, because only the robot knows its speed.
